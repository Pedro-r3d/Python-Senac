# Projeto Final Django
Projeto final a ser desenvolvido usando o framework Django do Python.

## Objetivo
Desenvolver um projeto Django com o intuito de apresentar uma solução para um problema a ser definido pelo grupo, mas que deve conter alguns requisitos mínimos para ser entregue.

## Problema
O grupo deve pensar e buscar um problema para ser solucionado com o projeto Django. 
Exemplos: 
- Uma empresa está com problemas para gerenciar os chamados abertos pelos colaboradores com a equipe de suporte de TI. (Sistema de Gerenciamento de Chamados)
- Uma loja não possui um controle eficiente dos produtos disponíveis, enfrentando problemas com falta de mercadorias e produtos parados no estoque. (Sistema de Controle de Estoque)
- Os colaboradores precisam solicitar materiais de escritório, mas a empresa não possui um processo organizado para registrar e acompanhar os pedidos. (Sistema de Solicitação de Materiais)
- Uma equipe tem dificuldades para organizar as atividades, definir responsáveis, acompanhar prazos e identificar tarefas atrasadas. (Sistema de Gerenciamento de Tarefas)
- Uma barbearia recebe agendamentos por WhatsApp e enfrenta problemas com horários duplicados, cancelamentos e organização dos profissionais. (Sistema de Agendamento de Barbearia)


## Requisitos funcionais mínimos para entrega de uma solução
- Deve haver 2 tipos de usuários no sistema (Usuário e administrador)
- Deve ser possível cadastrar novos usuários e fazer login usando um nome de usuário (cpf, email) e senha. Usar funcionalidade de autenticação e grupo de usuário do próprio django.
- Deve haver validações dos campos ao cadastrar e alterar registros.
- Deve haver NO MÍNIMO 5 telas no sistema. Pode haver mais.
- Deve haver um header no site. Pode haver um footer.
- CRUD - O projeto deve contem as 4 operações básicas de um sistema (Criar, ler atualizar e excluir registros)
- O sistema deve resolver algum problema. Além das 4 operações do CRUD, deve haver mais alguma funcionalidade que agregue valor ao projeto.


## Requisitos não funcionais para entrega da solução
- O site deve ser intuitivo para o usuário navegar e executar ações. (Layout bem estruturado e amigável. Cores nos elementos que condizem com o layout ou a ação que o elemento vai executar).
- Pode usar CSS puro ou Bootstrap.
